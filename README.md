# Forever Companion

A free, non-commercial, local desktop companion and interactive progression guide for WoW Forever.

## Project status

In development. The progression guide is being researched in stages, and the desktop companion is planned. The project is not affiliated with Blizzard Entertainment or ForeverDB.

## Planned features

- Priest (Discipline and Holy) leveling and character progression from level 1 to 60.
- Gear comparison, healing and mana efficiency calculations, and attainable best-in-slot recommendations.
- Dungeon and quest prerequisites, professions, enchantments, and progression checklists.
- A Markdown-based guide with an automatically generated offline HTML interface.
- Local character snapshots and progress tracking, without automated gameplay.

## Data source and attribution

**Data source: [ForeverDB.net](https://foreverdb.net/).**

ForeverDB will be visibly credited with a link wherever its data is displayed. API access is being requested for item, spell, quest, dungeon and profession research. API usage will respect the provider's terms, permitted caching and rate limits. API keys will remain private and will not be committed to this repository. No raw API data is published here.

Official WoW Forever information and patch notes will be prioritized alongside ForeverDB. Classic data, where used, will be clearly labeled. Unverified information will be marked as such.
